## 🌟 معرفی پروژه

این پلتفرم با هدف هوشمندسازی و تسهیل ارتباط بین واحدهای صنعتی، مالکان کارگاه‌ها، تامین‌کنندگان، خریداران و جویندگان کار طراحی شده است. کاربران و بازدیدکنندگان می‌توانند به راحتی در میان صدها کارگاه صنعتی جستجو کرده، موقعیت دقیق جغرافیایی سوله‌ها را روی نقشه ماهواره‌ای مشاهده کنند، محصولات را بررسی نمایند، درخواست استعلام قیمت (RFQ) ارسال کنند و از آگهی‌های شغلی و املاک صنعتی شهرک باخبر شوند.

مالکان واحدهای تولیدی دارای **داشبورد اختصاصی و یکپارچه** در منوی حساب کاربری برای مدیریت مشخصات کارگاه، محصولات، موقعیت مکانی با قابلیت درگ روی نقشه، نظرات، پیام‌ها و استعلام‌های دریافتی هستند.

## 🏗 معماری و تکنولوژی‌ها

این پروژه بر اساس معماری مدرن **Full-Stack (Vite + Express + PostgreSQL/Drizzle + Leaflet + PWA)** پیاده‌سازی شده است:

### 🔹 فرانت‌اند (Frontend)
- **React 19** با پشتیبانی از TypeScript
- **Vite 6** جهت بیلد فوق‌العاده سریع و ماژولار
- **Tailwind CSS v4** برای استایل‌دهی مدرن، واکنش‌گرا (Responsive) و تم استاندارد
- **Lucide React** جهت آیکون‌های برداری باکیفیت و استاندارد
- **Leaflet & React-Leaflet** برای پیاده‌سازی نقشه شهرک، لایه‌های خیابان و تصاویر ماهواره‌ای
- **Framer Motion / Motion** برای انیمیشن‌ها و ترنزیشن‌های روان UI
- **React Hot Toast** برای نمایش اعلان‌های زنده و پیام‌های سیستم
- **Browser Image Compression** برای فشرده‌سازی خودکار تصاویر قبل از آپلود
- **PWA (Progressive Web App)** برای امکان نصب اپلیکیشن روی گوشی و دسکتاپ

### 🔹 بک‌اند (Backend)
- **Express.js** در محیط Node.js
- **Esbuild** جهت بیلد کامپایل شده CommonJS سِروِر در محیط تولید (`dist/server.cjs`)
- **Nodemailer** جهت ارسال ایمیل‌های تایید و OTP از طریق سرویس SMTP
- **Cookie Parser & JWT** برای احراز هویت امن کاربر و نشست‌ها

### 🔹 پایگاه داده و ORM
- **PostgreSQL / Cloud SQL** به عنوان پایگاه داده اصلی
- **Drizzle ORM & Drizzle Kit** برای مدیریت اسکیما، کوئری‌ها و مایگریشن‌های تایپ‌ایمن

### 🔹 هوش مصنوعی و سرویس‌های بیرونی
- **Google Gemini API (`@google/genai`)**: برای تولید خودکار و هوشمند کلمات کلیدی سئو، توضیحات جذاب محصولات و بهینه‌سازی محتوای واحدهای صنعتی.
- **سامانه‌های پیامک (SMS Gateways)**: پشتیبانی از درگاه‌های مختلف پیامک با الگوی پترن کد تایید یکبار مصرف (OTP).

## ⚡ قابلیت‌ها و ویژگی‌های کلیدی

### ۱. بانک اطلاعات کارگاه‌ها و واحدهای صنعتی
- دسته‌بندی تخصصی (فلزی، شیمیایی، غذایی، برق و الکترونیک، نساجی، سلولزی، خدماتی و...)
- جستجوی بلادرنگ بر اساس نام، زمینه فعالیت، کلمات کلیدی سئو و آدرس
- ثبت موقعیت جغرافیایی روی نقشه و امکان مسیریابی مستقیم (Google Maps / نشان)
- اطلاعات کامل تماس (تلفن ثابت، موبایل ۱ و ۲، ایمیل، وب‌سایت)

### ۲. نقشه تعاملی و ثبت موقعیت کارگاه‌ها (Interactive Map & Location Picker)
- نمایش تمامی واحدهای صنعتی ثبت‌شده روی نقشه با مارکرهای تعاملی
- سوئیچ بین لایه‌های **نقشه استاندارد شهری (Street View)** و **تصاویر ماهواره‌ای دقیق (Satellite)**
- ابزار انتخاب مکان کارگاه (`MapLocationPicker`) با امکان کلیک، جابجایی پین (Drag & Drop) و دریافت مختصات GPS زنده
- تولید هوشمند لینک‌های مسیریابی برای مراجعه‌کنندگان

### ۳. سیستم مدیریت محصولات و کاتالوگ آنلاین
- ثبت محصولات هر کارگاه به همراه تصاویر باکیفیت، قیمت، مشخصات فنی و کلمات کلیدی سئو
- کاتالوگ جامع محصولات برای هر واحد صنعتی با فیلتر دسته‌بندی
- دکمه ارسال سریع درخواست استعلام قیمت برای هر محصول

### ۴. سیستم استعلام قیمت (RFQ - Request for Quote)
- ثبت درخواست قیمت و تیراژ مورد نیاز توسط مشتریان بدون پیچیدگی
- مدیریت استعلام‌ها در داشبورد با وضعیت‌های (`pending`, `replied`, `cancelled`)

### ۵. آگهی‌ها، نیازمندی‌ها و استخدام (Classifieds)
- بخش اختصاصی آگهی‌های استخدام و جذب نیروی کار در شهرک صنعتی
- آگهی‌های رهن، اجاره و فروش سوله، کارگاه و زمین صنعتی
- آگهی‌های خرید و فروش ماشین‌آلات و تجهیزات دست دوم

### ۶. سیستم نظرات، امتیازدهی و چت مستقیم
- ثبت نظر و امتیاز به واحدهای تولیدی
- پیام‌رسانی و ارتباط مستقیم بین خریدار و مدیر کارگاه

### ۷. پنل مدیریت پیشرفته (Admin Dashboard)
- تایید، ویرایش و نظارت بر کلیه واحدهای صنعتی، آگهی‌ها و محصولات
- مدیریت تنظیمات درگاه پیامک و الگوهای ارسال
- مدیریت تنظیمات ایمیل (SMTP)
- پشتیبان‌گیری کامل پایگاه داده (JSON Backup) و بازیابی اطلاعات (Restore)

| جدول (Table) | توضیحات | فیلدهای اصلی |
| :--- | :--- | :--- |
| **`users`** | اطلاعات کاربران و مدیران | `uid`, `name`, `phone`, `email`, `passwordHash`, `lastLoginAt`, `createdAt` |
| **`units`** | کارگاه‌ها و واحدهای تولیدی | `id`, `ownerId`, `name`, `phone`, `mobile1`, `mobile2`, `address`, `category`, `latitude`, `longitude`, `seoKeywords`, ... |

| **`classifieds`** | آگهی‌ها و نیازمندی‌ها | `id`, `ownerId`, `type` (job/real_estate/classified), `title`, `description`, `phone`, `price`, `category`, `location` |

## 🔐 احراز هویت و امنیت

سامانه از دو روش امن و مجزا برای ورود و عضویت پشتیبانی می‌کند:

1. **ورود و ثبت‌نام پیامکی (SMS OTP)**:
   - ورود سریع و بدون رمز عبور تنها با وارد کردن شماره موبایل
   - ارسال کد ۵ رقمی یکبار مصرف به شماره همراه کاربر (یا نمایش در شبیه‌ساز توسعه)
   - اعتبار کدهای ارسال‌شده ۵ دقیقه است.

2. **ورود با ایمیل و کلمه عبور (Email & Password)**:
   - ورود با آدرس ایمیل و رمز عبور اختصاصی
   - **تعیین / فراموشی رمز عبور با ایمیل (Forgot / Set Password)**: در صورت نداشتن رمز یا فراموشی آن، کاربر می‌تواند با زدن گزینه «فراموشی / تعیین رمز عبور»، کد تایید ۵ رقمی به ایمیل خود دریافت کرده و بلافاصله رمز عبور جدید تعیین کند.

3. **حفاظت امنیتی ورود مجدد (2FA / Security Check)**:
   - الزامی شدن تایید دو مرحله‌ای با ایمیل در صورت گذشت بیش از ۷ روز از آخرین ورود با رمز عبور

## 👑 راهنمای ورود به پنل مدیریت (Admin Panel)

پس از پابلیش برنامه، برای ورود به بخش مدیریت کل سامانه شهرک صنعتی:

1. **ورود به سیستم**:
   - روی دکمه **ورود / عضویت** در هدر سایت کلیک کنید.
   - با ایمیل مدیر سامانه (`manamalat@gmail.com`) یا شماره همراه خود وارد شوید.
   - *نکته:* در صورت نیاز به تعیین یا تغییر رمز، از گزینه «فراموشی / تعیین رمز عبور» با ارسال کد به ایمیل استفاده کنید.

2. **دسترسی به پنل**:
   - پس از ورود موفق، روی **آیکون آدمک (پروفایل کاربری)** در بالای صفحه کلیک کنید.
   - گزینه **«پنل مدیریت شهرک صنعتی»** در منو نمایش داده می‌شود و با کلیک روی آن وارد پنل مدیریت می‌شوید.
   - همچنین می‌توانید مستقیماً به مسیر `/admin` بروید.

3. **مدیریت کارگاه‌ها و تایید واحدها**:
   - در تب **«واحدهای صنعتی»**، لیست تمام کارگاه‌های ثبت‌شده قابل مشاهده است.
   - برای نمایش هر واحد در صفحه اصلی و نقشه، وضعیت آن باید **«تایید شده (approved)»** باشد.
   - می‌توانید هر واحد را ویرایش کرده، تایید یا در صورت نیاز رد کنید.

## 👤 نقش‌ها و دسترسی‌های کاربران

- **بازدیدکننده (Guest)**:
  - مشاهده واحدهای صنعتی، نقشه، محصولات، آگهی‌ها و بنرها
  - جستجو و فیلتر اطلاعات و ثبت درخواست استعلام قیمت

- **مالک واحد صنعتی (Unit Owner)**:
  - دسترسی به «کارگاه من» از طریق منوی آدمک
  - ثبت و ویرایش مشخصات واحد، موقعیت مکانی روی نقشه
  - افزودن، ویرایش و حذف محصولات و مدیریت استعلام‌ها

- **مدیر سیستم (System Admin)**:
  - دسترسی به پنل مدیریت ارشد از طریق منوی آدمک
  - نظارت بر کلیه واحدها، آگهی‌ها، درگاه‌های پیامک، ایمیل و پشتیبان‌گیری داده‌ها

## 🔑 راهنمای متغیرهای محیطی (Environment Variables)

فایل `.env` نمونه بر اساس `.env.example`:

```env
# Database Credentials
DATABASE_URL="postgresql://user:password@localhost:5432/industrial_park"

# JWT Secret
JWT_SECRET="your-super-secret-jwt-key"

# Gemini AI API Key (Server-side)
GEMINI_API_KEY="your-google-gemini-api-key"

# SMTP Email Configuration (Nodemailer)
SMTP_HOST="smtp.example.com"
SMTP_PORT="587"
SMTP_USER="no-reply@industrialpark.ir"
SMTP_PASS="your-smtp-password"
SMTP_FROM="no-reply@industrialpark.ir"

# SMS Gateway Configuration
KAVENEGAR_API_KEY=""
SMS_SENDER=""
SMS_PROVIDER="kavenegar"
```

### مرحله ۱: انتقال سورس پروژه به گیت‌هاب (GitHub)


### مرحله ۲: اتصال به سرور VPS و نصب پیش‌نیازها

با ابزار SSH (یا نرم‌افزار PuTTY / Termius) وارد سرور لینوکس خود شوید:
```bash
ssh root@YOUR_SERVER_IP
```

دستورات زیر را برای آپدیت سرور و نصب **Node.js 22**، **Git**، **Nginx** و **PM2** اجرا کنید:

```bash
# بروزرسانی مخازن سرور
sudo apt update && sudo apt upgrade -y

# نصب ابزارهای ضروری
sudo apt install -y curl git ufw nginx

# نصب Node.js نسخه 22 (LTS)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# نصب PM2 جهت اجرای دائمی برنامه در پس‌زمینه
sudo npm install -g pm2
```

### مرحله ۳: دریافت پروژه از گیت‌هاب روی سرور

```bash
# رفتن به دایرکتوری وب سرور
cd /var/www

# دریافت پروژه از گیت‌هاب
git clone https://github.com/YOUR_USERNAME/industrial-park.git

# ورود به پوشه پروژه
cd industrial-park

# دسترسی اجرایی به اسکریپت استقرار

```

### مرحله ۴: تنظیم متغیرهای محیطی (`.env`)

فایل نمونه را کپی کرده و اطلاعات پایگاه‌داده و متغیرهای لازم را وارد کنید:

```bash
cp .env.example .env
nano .env
```

*متغیرهای مهم را مطابق تنظیمات خود تکمیل نمایید:*
- `DATABASE_URL` (آدرس اتصال به PostgreSQL داخلی سرور یا سرویس‌های ابری مثل Neon / Supabase)
- `ADMIN_EMAIL` (ایمیل مدیر اصلی سیستم: `manamalat@gmail.com`)
- `JWT_SECRET` (یک رشته تصادفی و امن)

برای ذخیره فایل در `nano`، کلید‌های `Ctrl + O` و سپس `Enter` و برای خروج `Ctrl + X` را بزنید.

### مرحله ۵: نصب پکیج‌ها، ساخت و اجرای برنامه با PM2

### مرحله ۶: تنظیم وب‌سرور Nginx و اتصال دامنه

برای اتصال دامنه و باز شدن برنامه روی پورت استاندارد ۸۰ و ۴۴۳ (SSL):

۱. فایل کانفیگ جدیدی برای Nginx بسازید:
```bash
sudo nano /etc/nginx/sites-available/industrialpark
```

۲. محتویات فایل `nginx.conf.example` موجود در پروژه را در آن کپی کرده و دامنه خود را به جای `your-domain.com` قرار دهید.

۳. فعال‌سازی تنظیمات و ری‌استارت Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/industrialpark /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl restart nginx
```

۴. **نصب رایگان گواهی امنیتی SSL (HTTPS)**:
```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com -d www.your-domain.com
```
