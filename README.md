## 🌟 معرفی پروژه

این پلتفرم با هدف هوشمندسازی و تسهیل ارتباط بین واحدهای صنعتی، مالکان کارگاه‌ها، تامین‌کنندگان، خریداران و جویندگان کار طراحی شده است. کاربران و بازدیدکنندگان می‌توانند به راحتی در میان صدها کارگاه صنعتی جستجو کرده، محصولات را بررسی نمایند، درخواست استعلام قیمت (RFQ) ارسال کنند و از آگهی‌های شغلی و املاک صنعتی شهرک باخبر شوند.

مالکان واحدهای تولیدی نیز دارای **داشبورد اختصاصی** برای مدیریت کامل اطلاعات واحد، کالاها، عکس‌ها، موقعیت جغرافیایی روی نقشه، کلمات کلیدی سئو و استعلام‌های دریافتی می‌باشند.

## 🏗 معماری و تکنولوژی‌ها

این پروژه بر اساس معماری مدرن **Full-Stack (Vite + Express + PostgreSQL)** پیاده‌سازی شده است:

### 🔹 فرانت‌اند (Frontend)
- **React 19** با پشتیبانی از TypeScript
- **Vite 6** جهت بیلد فوق‌العاده سریع و ماژولار
- **Tailwind CSS v4** برای استایل‌دهی مدرن و واکنش‌گرا (Responsive)
- **Lucide React** جهت آیکون‌های برداری باکیفیت
- **Framer Motion** برای انیمیشن‌ها و ترنزیشن‌های روان UI
- **React Hot Toast** برای نمایش اعلان‌های زنده به کاربر
- **Browser Image Compression** برای فشرده‌سازی تصاویر پیش از آپلود

### 🔹 بک‌اند (Backend)
- **Express.js** در محیط Node.js
- **Esbuild** جهت بیلد کامپایل شده CommonJS سِروِر در تولید (`dist/server.cjs`)
- **Nodemailer** جهت ارسال ایمیل‌های تایید و OTP از طریق سرویس SMTP
- **Cookie Parser & JWT** برای احراز هویت امن کاربر و نشست‌ها

### 🔹 پایگاه داده و ORM
- **PostgreSQL / Cloud SQL** به عنوان پایگاه داده اصلی
- **Drizzle ORM & Drizzle Kit** برای مدیریت اسکیما، کوئری‌ها و مایگریشن‌های تایپ‌ایمن

### 🔹 هوش مصنوعی و سرویس‌های بیرونی
- **Google Gemini API (`@google/genai`)**: برای تولید هوشمند کلمات کلیدی سئو، توضیحات جذاب محصولات و بهینه‌سازی محتوای واحدهای صنعتی.
- **سامانه‌های پیامک (SMS Gateways)**: پشتیبانی از کاوه‌نگار، IPPanel، ملی‌پیامک، فراز اس‌ام‌اس و ارسال پترن (Pattern SMS).

## ⚡ قابلیت‌ها و ویژگی‌های کلیدی

### ۱. بانک اطلاعات کارگاه‌ها و واحدهای صنعتی
- دسته‌بندی تخصصی (فلزی، شیمیایی، غذایی، برق و الکترونیک، نساجی، سلولزی، خدماتی و...)
- جستجوی پیشرفته بر اساس نام، زمینه فعالیت، کلمات کلیدی سئو و آدرس
- ثبت موقعیت جغرافیایی روی نقشه و لینک‌دهی به مسیریاب‌ها
- اطلاعات کامل تماس (تلفن ثابت، موبایل ۱ و ۲، ایمیل، وب‌سایت)

### ۲. سیستم مدیریت محصولات و کالاها
- ثبت محصولات هر کارگاه به همراه تصویر، قیمت، توضیحات کامل و کلمات کلیدی سئو
- کاتالوگ آنلاین محصولات برای هر واحد صنعتی
- دکمه ارسال سریع درخواست استعلام قیمت برای هر محصول

### ۳. سیستم استعلام قیمت (RFQ - Request for Quote)
- خریداران می‌توانند بدون نیاز به ثبت‌نام پیچیده درخواست قیمت و تعداد مورد نیاز را ثبت کنند.
- مالکان کارگاه‌ها در داشبورد خود لیست استعلام‌ها را مشاهده کرده و وضعیت آن را مدیریت می‌کنند (`pending`, `replied`, `cancelled`).

### ۴. آگهی‌ها، نیازمندی‌ها و املاک صنعتی (Classifieds)
- بخش اختصاصی آگهی‌های استخدام و جذب نیرو در شهرک صنعتی
- آگهی‌های رهن، اجاره و فروش سوله، کارگاه و زمین صنعتی
- آگهی‌های خرید و فروش ماشین‌آلات و تجهیزات دست دوم

### ۵. بنرهای تبلیغاتی و اسپانسری (Advertising Banners)
- امکان نمایش بنرهای ویژه در بالای صفحات
- مدیریت بنرها از طریق پنل مدیریت با نشان‌های ویژه (`ویژه`, `طلایی`, `تخفیف`)

### ۶. پنل مدیریت پیشرفته (Admin Panel)
- **مدیریت واحدهای صنعتی**: تایید، ویرایش و حذف واحدهای ثبت شده
- **مدیریت سامانه پیامک**: تنظیم سرویس‌دهنده پیامک، کلید API، شماره خط ارسال‌کننده و الگوی پترن کد تایید
- **مدیریت تنظیمات ایمیل (SMTP)**: تنظیم سرور SMTP، پورت، نام‌کاربری و رمزعبور جهت ارسال ایمیل‌های تایید
- **پشتیبان‌گیری و بازیابی (Backup & Restore)**: خروجی کامل JSON از اطلاعات پایگاه داده و امکان بازگردانی داده‌ها

## 🗄 ساختار پایگاه داده (Database Schema)

اسکیمای پروژه در مسیر `src/db/schema.ts` با استفاده از Drizzle ORM تعریف شده است:

| جدول (Table) | توضیحات | فیلدهای اصلی |
| :--- | :--- | :--- |
| **`users`** | اطلاعات کاربران و مدیران | `uid`, `name`, `phone`, `email`, `passwordHash`, `lastLoginAt`, `createdAt` |
| **`units`** | کارگاه‌ها و واحدهای تولیدی | `id`, `ownerId`, `name`, `phone`, `mobile1`, `mobile2`, `address`, `category`, `latitude`, `longitude`, `seoKeywords`, ... |
| **`products`** | محصولات هر واحد صنعتی | `id`, `unitId`, `ownerId`, `name`, `description`, `image`, `price`, `seoKeywords`, `createdAt` |
| **`banners`** | بنرهای تبلیغاتی | `id`, `companyName`, `title`, `description`, `image`, `badge`, `phone`, `createdAt` |
| **`classifieds`** | آگهی‌ها و نیازمندی‌ها | `id`, `ownerId`, `type` (job/real_estate/classified), `title`, `description`, `phone`, `price`, `category`, `location` |
| **`quotes`** | استعلام‌های قیمت ثبت شده | `id`, `productId`, `unitId`, `buyerName`, `buyerPhone`, `quantity`, `description`, `status` |
| **`settings`** | تنظیمات دینامیک سیستم | `key` (primaryKey), `value`, `updatedAt` |
| **`otps`** | کدهای فعال یکبار مصرف | `phone` (یا ایمیل), `code`, `expiresAt` |
| **`smsLogs`** | لاگ‌های ارسال پیامک | `id`, `phone`, `code`, `provider`, `template`, `status`, `timestamp` |

## 🔐 احراز هویت و امنیت

سیستم احراز هویت پروژه به صورت هیبریدی و دو لایه پیاده‌سازی شده است:

1. **ورود و ثبت‌نام پیامکی (SMS OTP)**:
   - ارسال کد ۵ رقمی یکبار مصرف به شماره موبایل کاربر
   - اعتبار ۵ دقیقه‌ای کد تایید
   - ثبت نام سریع و احراز هویت بدون نیاز به حفظ کلمه عبور

2. **ورود و ثبت‌نام ایمیلی (Email OTP)**:
   - ارسال کد تایید ۵ رقمی به آدرس ایمیل از طریق سرویس SMTP Nodemailer
   - قالب HTML شکیل و دو زبانه برای کدهای تایید

3. **حفاظت امنیتی ورود مجدد (2FA / Security Check)**:
   - در صورت ورود با ایمیل و رمز عبور، اگر بیش از **۷ روز** از آخرین ورود کاربر به سیستم گذشته باشد، سیستم به طور خودکار یک کد تایید به ایمیل کاربر فرستاده و تایید آن را برای ورود الزامی می‌کند.

## 👤 نقش‌ها و دسترسی‌های کاربران

- **بازدیدکننده (Guest)**:
  - مشاهده واحدهای صنعتی، محصولات، آگهی‌ها و بنرها
  - جستجو و فیلتر اطلاعات
  - ثبت درخواست استعلام قیمت برای محصولات

- **مالک واحد صنعتی (Unit Owner)**:
  - ثبت و ویرایش مشخصات واحد صنعتی خود
  - افزودن، ویرایش و حذف محصولات
  - مشاهده و پاسخ به استعلام‌های قیمت دریافتی
  - ثبت آگهی‌های شغلی و املاک مربوط به واحد خود

- **مدیر سیستم (System Admin)**:
  - دسترسی کامل به کلیه بخش‌های سیستم
  - تایید یا ویرایش تمامی کارگاه‌ها و آگهی‌ها
  - مدیریت تنظیمات درگاه پیامک و تنظیمات ایمیل SMTP
  - دانلود پشتیبان پایگاه داده و بازگردانی اطلاعات

## 🔑 راهنمای متغیرهای محیطی (Environment Variables)

برای راه‌اندازی پروژه، فایل `.env` را بر اساس نمونه زیر در ریشه پروژه ایجاد نمایید:

```env
# Database Credentials
DATABASE_URL="postgresql://user:password@localhost:5432/industrial_park"

# JWT Secret
JWT_SECRET="your-super-secret-jwt-key"

# Gemini AI API Key
GEMINI_API_KEY="your-google-gemini-api-key"

# SMTP Email Configuration (Nodemailer)
SMTP_HOST="smtp.example.com"
SMTP_PORT="587"
SMTP_USER="no-reply@industrialpark.ir"
SMTP_PASS="your-smtp-password"
SMTP_FROM="no-reply@industrialpark.ir"

# SMS Gateway Configuration (Optional - Can also be set in Admin Panel)
KAVENEGAR_API_KEY=""
SMS_SENDER=""
SMS_PROVIDER="kavenegar"
```

## 🛠 راهنمای نصب و راه‌اندازی

### پیش‌نیازها
- **Node.js** نسخه 18 یا بالاتر
- **npm** یا **yarn**
- پایگاه داده **PostgreSQL** (یا متصل به Cloud SQL)

### گام اول: دریافت پروژه و نصب وابستگی‌ها
```bash
# نصب بسته و وابستگی‌های پروژه
npm install
```

### گام دوم: تنظیم پایگاه داده و بروزرسانی اسکیما
```bash
# اعمال تغییرات اسکیما روی دیتابیس
npx drizzle-kit push
```

### گام سوم: اجرای محیط توسعه (Development)
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

### گام چهارم: ساخت نسخه نهایی برای تولید (Production Build)
```bash
# بیلد فرانت‌اند و کامپایل سرور
npm run build

# اجرای سرور در حالت تولید
npm start
```

## 📜 اسکریپت‌های اجرایی

| اسکریپت | دستور | توضیحات |
| :--- | :--- | :--- |
| `npm run dev` | `tsx server.ts` | اجرای سرور توسعه به همراه Vite Middleware |
